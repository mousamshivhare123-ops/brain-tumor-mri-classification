# Final submission checklist

This package includes the source code and report. Before calling it a completed experimental submission, run the pipeline on your computer and add the actual generated outputs:

- [ ] Run `prepare_data.py` and retain the printed image counts.
- [ ] Inspect the split folders and check duplicate/near-duplicate images across splits.
- [ ] Run `train.py` to produce both trained models and comparison metrics.
- [ ] Run `evaluate.py` and inspect the classification report and confusion matrix.
- [ ] Fill the Results table in `Project_Report.docx` with actual metrics; do not invent results.
- [ ] Include generated `results/` plots and metrics if your instructor requests them.
- [ ] Add your name, course, institution, and submission date to the report.
- [ ] Verify dataset attribution and license requirements before publishing the dataset or code publicly.
- [ ] Do not present this academic prototype as a medical diagnostic device.
